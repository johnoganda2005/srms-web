# Chuka University Student Records Management System (SRMS)

A full-stack, secure web application designed to manage academic records, courses, enrollments, and examination results for Chuka University.

## 🚀 Technologies Used
- **Backend:** Java 17, Spring Boot, Spring Data JPA
- **Database:** MySQL
- **Security:** Spring Security (Custom Login, Email Password Reset)
- **Frontend:** HTML, CSS, JavaScript, Bootstrap 5, Chart.js, FontAwesome
- **Tools:** Maven, IntelliJ IDEA, GitHub

## ✨ Key Features
- **Secure Authentication:** Custom login page & email password reset via secure tokens.
- **Dashboard:** Real-time Pie & Bar charts for student demographics and enrollments.
- **Student Management:** Full CRUD, pagination (for 2000+ records), and CSV export.
- **Bulk Enrollment:** Fast way to enroll hundreds of students at once with a search filter.
- **Examination Results:** Auto-calculate grades (A-F) based on inputted scores.
- **Academic Reports:** Generate transcripts with GPA calculation and download them as PDFs.
- **Course Allocation:** Assign tutors to specific courses for given semesters.
